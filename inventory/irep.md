## Service groups

How the 7 services divide by role, as confirmed by the platform team on 2026-11-11. Keywords: grouping, SmartSync, Priority Replication, iRep, adapter, orchestrator.

| Group | Services |
|---|---|
| Configuration gateway | ComINT |
| Export side (sync+) | ExportCDT, ExportDCS |
| Import side (sync+) | ImportDES, ImportDSC, ImportRBP |
| Reporting / inspection (sync+) | ComPBR |

- **iRep** is called **SmartSync+ (sync+)** internally. It replicates whole tables per *replica type* (1 NORMAL, 2 ATTACHMENTS, 3 PAL_REP, 4 REP2X, 5 REP2I) using SQL Server change tracking on the sending side and staging databases (REP2X on export, REP2I on import).
- **ComINT** is the configuration gateway: every other iRep service asks it (`ComINT/GetDbConfigurationDetails`) for the per-replica-type connection settings.
- **Export side:** ExportCDT (change tracking → REP2X record-sync tables) → ExportDCS (packet generation per vessel) → RepIntegration `Integration/TransferGeneral` → RepTransfer → SmartSync (RepAzure/RepSbus).
- **Import side:** ImportDES (validate and read incoming packets into REP2I) → ImportDSC (schema compare / replica table create-alter) → ImportRBP (apply staged rows to PAL tables and call application endpoints).
- **ComPBR** reads packet headers/queues and zip packet content for reporting and manual inspection.
- The transport (SmartSync) and the RepIntegration/RepTransfer hand-off are documented in `inventory/ms-rep.md`.
